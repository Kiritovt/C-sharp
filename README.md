# C# Learning Path

This repository documents my progression in C# and .NET development, from programming fundamentals and object-oriented programming to data persistence, relational databases and ASP.NET Core Web APIs.

The projects are intentionally preserved as part of the learning process, showing how my approach to software design, data access and backend development has evolved over time.

## Projects

### First_Project
Initial C# exercises focused on programming fundamentals, syntax, control flow and basic problem-solving.

### ShoppingList_Project
Console application created to practice collections, user input, control flow and basic application logic.

### RegisterOfStudent_project
Student management application with functionality for adding students, managing grades, displaying information and calculating averages.

### LocalBank_project
Simple banking simulation used to practice classes, objects, encapsulation and separation of responsibilities.

### ContactList_Project
Contact management application with JSON persistence using `System.Text.Json`, including operations for adding, searching and removing contacts.

### BookContactsPostgre_Project
Evolution of the contact management project using PostgreSQL and Npgsql.

The project introduced:
- relational database persistence
- parameterized SQL queries
- CRUD operations
- repository-based data access
- LINQ for filtering and ordering

### LibraryManager
Library management application developed using Entity Framework Core and PostgreSQL.

Main concepts:
- entities and relationships
- one-to-many relationships
- `DbContext`
- repositories
- LINQ
- Entity Framework Core change tracking

### LibraryApi
ASP.NET Core Web API representing the transition from console applications to backend web development.

Current architecture includes:
- Controllers
- Services
- Repositories
- DTOs
- Dependency Injection
- Entity Framework Core
- PostgreSQL
- RESTful endpoints
