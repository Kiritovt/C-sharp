Crea un programma per gestire degli studenti.

Ogni studente deve avere:

nome;
cognome;
una lista di voti.

Menu:

1. Add student
2. Show students
3. Add grade
4. Show student grades
5. Calculate student average
0. Exit

Obiettivi principali:

creare una classe Student;
utilizzare una List<Student>;
inserire una List<double> dentro ogni studente;
selezionare uno studente tramite posizione;
aggiungere voti;
calcolare la media dei voti;
gestire studenti senza voti.
